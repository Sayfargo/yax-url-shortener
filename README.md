## Кодогенерация

В проекте используется генератор методов `Reset()` (`cmd/reset`) для структур, помеченных комментарием `// generate:reset`.

Для запуска генерации выполните из корня репозитория:

```bash
go generate ./...
```

При необходимости запустить генератор напрямую с другими исключаемыми директориями:

```bash
go run ./cmd/reset/main.go -i ".git .github api migrations"
```
